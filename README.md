# iCOOL Steel Studio

منصة بارامترية لدراسة الهياكل الحديدية: مظلات وأسطح شمسية، برغولا، هنغار، مع دراسة ظلال،
غرفة كهرباء ثلاثية الأبعاد، تابلوهات AC/DC، خط أحادي، وتقارير فنية قابلة للطباعة.

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح (Chrome/Edge). لا يحتاج build.

## الصفحات
| الملف | الوصف |
|---|---|
| `index.html` | المنصة الرئيسية |
| `panel-asbuilt-studio.html` | استوديو تحويل صور التابلوهات المنفّذة إلى Shop Drawings |
| `deye-realism-pack.js` | حزمة واقعية Deye/Deye ESS لغرفة الكهرباء |

انظر `DEPLOY.md`.
