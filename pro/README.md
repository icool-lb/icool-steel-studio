# iCOOL Solar Pro

نسخة تشغيلية محلية لمنصة تصميم وتسعير أنظمة الطاقة الشمسية.

## التشغيل السريع
افتح `index.html` مباشرة. للحصول على دعم PWA والحفظ المؤكد، ارفع المجلد إلى أي استضافة ثابتة مثل Vercel أو Netlify أو GitHub Pages.

## الوظائف
- إدارة العملاء والمشاريع
- كشف الموقع
- تحليل الأحمال
- اختيار ألواح/إنفرتر/بطاريات من المكتبة
- حساب PV والإنتاج والبطاريات والـStrings والتحقق الأساسي
- مخطط هيكل أولي Canvas وكميات تقريبية
- BOQ والكلفة الداخلية وسعر البيع والربح
- تقرير فني ودراسة جدوى
- طباعة PDF من المتصفح
- نسخة احتياطية JSON واستعادة
- حفظ محلي LocalStorage

## ملاحظة هندسية
نتائج التصميم والهيكل أولية ويجب مراجعتها وفق datasheet الفعلي، درجات الحرارة، معايير الحماية، أحمال الرياح، وطبيعة السطح قبل التنفيذ.
